# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately: use GitHub's **Report a vulnerability** button on the
repository's Security tab, or email the maintainer. Do not open a public issue. You will get an
answer within three working days.

Include what you found, how to reproduce it, and what an attacker could do with it. Please do not
access other people's data, run denial-of-service tests, or test against production without
permission.
